# 2.5D-Gomoku-Mayhem — 증강 오목 3D 프로토타입

인스크립션 풍(어두운 방 · 촛불 · 나무 판 · 손에 든 카드)의 3D 증강 오목 프로토타입입니다.
Three.js(r128)를 `js/`에 포함해서 **빌드·설치 없이** `index.html`을 브라우저로 열면 바로 실행됩니다.

## 실행

- **윈도우**: `run.bat` 더블클릭 / **맥·리눅스**: `run.sh` 실행 → 브라우저에서 `http://localhost:8000` 이 열립니다. (Python 필요)
- `index.html`을 직접 더블클릭해도 실행되지만, 이 경우 **이미지 에셋(일러스트·맵 이미지)은 로드되지 않고** 기본 그림으로 표시됩니다.

## 조작 (로컬 2인 대전, 흑 선공)

- 판을 클릭해 돌을 둡니다. 마우스를 움직이면 카메라가 살짝 따라 움직입니다.
- 아래 손패 카드를 클릭하면 사용합니다. **턴당 카드 1장**, 카드를 써도 돌은 그대로 둡니다(별도 표기 제외).
- 대상을 고르는 카드(폭파·장벽)는 카드를 누른 뒤 판에서 칸을 클릭합니다. 같은 카드를 다시 누르거나 `Esc`로 취소합니다.
- 각 플레이어는 카드 6장을 한 번씩 쓸 수 있습니다.
- 승리: 같은 색 돌이 **정확히 5개**(식스센스 후 정확히 6개) 이어지면 승리, 장목은 승리가 아닙니다.

## 카드 (원본 `CARDS.md` 21장 중 6장)

| 카드 | 효과 | 턴 종료 |
|---|---|---|
| ⚡ 연속 착수 | 이번 턴에 3수까지 둠 (같은 턴에 둔 돌의 2칸 이내 금지). 1수 이상 둔 뒤 "턴 종료" 버튼 가능 | — |
| 💥 폭파 | 상대 돌 1개 제거 | — |
| ✨ 순간이동 | 내 돌 1개를 무작위 빈 칸으로 이동 | — |
| 🧱 장벽 | 빈 칸에 영구 장벽 (아무도 못 두고 줄도 끊김) | — |
| 👁️ 식스센스 | 승리 조건이 영구히 6목으로 | — |
| ☯️ 전세 역전 | 판의 흑·백 돌을 통째로 뒤바꿈 | ✔ |

## 일러스트 · 맵 교체

코드를 고치지 않고 **이미지를 넣고 `js/config.js`에 경로만 적으면** 교체됩니다. 자세한 규격은 [`assets/README.md`](assets/README.md).

- **카드 일러스트**: `assets/cards/`에 PNG(584×428 권장)를 넣고 `config.js`의 `cards`에 경로 지정. 없으면 자동 잉크 그림.
- **맵**: `config.js`의 `maps`에 항목을 추가 — 판 이미지, 테이블, 360° 배경, 돌 표면, 조명/안개/촛불/카메라. 맵이 2개 이상이면 화면 위쪽에 선택 메뉴가 생깁니다. 기본으로 "촛불 방"과 "달빛 방"이 들어 있습니다.

## 프로토타입의 단순화

- 폭파 후 그 자리를 2턴 막는 규칙은 아직 없습니다.
- 카드 선택(3장 중 1장)·전설 카드·봇·멀티플레이는 아직 없습니다.
- 효과음은 외부 파일 없이 WebAudio로 만든 임시 소리입니다.

## 파일

- `index.html` — 화면 뼈대 · HUD
- `js/config.js` — 일러스트·맵 설정 (여기만 고치면 됨)
- `js/main.js` — 3D 장면, 규칙, 카드, 입력 전부
- `assets/` — 일러스트·맵 이미지를 넣는 폴더
- `run.bat` / `run.sh` — 로컬 서버로 실행
- `js/three.min.js` — Three.js r128 (MIT, `js/THREE-LICENSE`)
