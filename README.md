# 2.5D-Gomoku-Mayhem — 증강 오목 3D 프로토타입

인스크립션 풍(어두운 방 · 촛불 · 나무 판 · 손에 든 카드)의 3D 증강 오목 프로토타입입니다.
Three.js(r128)를 `js/`에 포함해서 **빌드·설치 없이** `index.html`을 브라우저로 열면 바로 실행됩니다.

## 실행

- **윈도우**: `run.bat` 더블클릭 / **맥·리눅스**: `run.sh` 실행 → 브라우저에서 `http://localhost:8000` 이 열립니다. (Python 필요)
- `index.html`을 직접 더블클릭해도 실행되지만, 이 경우 **이미지 에셋(일러스트·맵 이미지)은 로드되지 않고** 기본 그림으로 표시됩니다.

## 메인 화면
- 시작하면 메인 화면이 나옵니다: **튜토리얼**(3단계) · **로컬 모드** · **봇전**(선공/후공 선택 후 1단계 봇과 대결, 단계 선택은 아직 없음) · **멀티플레이**(선공 선택 · 새 방 만들기 · 방 코드로 참가 화면만, 온라인 연결은 아직 없음).
- 우측 상단: ⚙️ 설정(움직임 줄이기 · 배경 음악 볼륨/음소거) · 한국어/English 전환. 설정은 브라우저에 저장됩니다.
- 방 코드 입력은 한글·러시아어·일본어 자판으로 쳐도 같은 자리의 영문으로 바뀝니다.
- 게임 중 좌측 상단 `← 메뉴로` 로 돌아옵니다.

## 조작 (로컬 2인 대전, 흑 선공)

화면은 두 가지 시점으로 나뉩니다.

| 시점 | 할 수 있는 것 |
|---|---|
| **카드 화면** (기본, 낮은 시점) | 화면 아래 가운데에 카드가 부채꼴로 겹쳐 있고, 마우스를 패 쪽으로 가져가면 위로 올라와 펼쳐집니다. **돌은 둘 수 없습니다.** |
| **직부감** (위에서 내려다보는 시점) | 판 전체가 크게 보이고, **여기서만 돌을 둘 수 있습니다.** 패는 모두 숨겨지고, **쓰기로 한 카드 한 장만 왼쪽 아래에** 떠 있습니다(카드를 안 썼으면 카드가 없음). |

- **카드 확인·발동**: 카드를 누르면 크게 확대돼서 자세히 볼 수 있습니다. 확대된 카드를 **한 번 더 누르면 능력이 발동**하고 직부감으로 이동합니다. 다른 곳을 누르거나 `Esc`로 닫을 수 있습니다.
- **돌 두기**: 카드 화면에서 **판을 누르면** 직부감으로 이동합니다. 직부감에서 칸을 눌러 돌을 둡니다.
- **시점 전환**: 직부감에서 판 바깥 테이블 누르기, 우측 상단 버튼, `V` 키.
- **카드가 쓰이면 가운데서 불타 사라지고, 다 탄 뒤에 효과가 적용됩니다.** 바로 발동하는 카드는 그 자리에서, 폭파·장벽처럼 대상을 고르는 카드는 왼쪽 아래에서 기다리다가 대상을 고르면 가운데로 와서 탑니다.
- 돌을 두면 턴이 끝나고, 다음 사람의 카드 화면으로 돌아갑니다.
- **턴당 카드 1장**, 카드를 써도 돌은 그대로 둡니다(별도 표기 제외).
- 대상을 고르는 카드(풍차·폭파·맞교환·순간이동·함정·장벽·보호막)는 발동 후 직부감에서 판의 칸을 클릭합니다(맞교환은 두 칸). 취소는 `Esc`.
- 승리: 같은 색 돌이 **정확히 5개**(식스센스 후 정확히 6개) 이어지면 승리, 장목은 승리가 아닙니다.

## 규칙 (원본 Gomoku-ARAM 에서 옮김)

- 같은 색 돌이 **정확히 5개**(식스센스 후 정확히 6개) 이어지면 승리, 장목은 승리가 아닙니다.
- **내 돌을 3개 둘 때마다 카드 3장 중 1장**을 골라 패에 넣습니다(화면 가운데에 3장이 펼쳐짐).
- 패는 **최대 4장**, 넘치면 가장 오래된 카드가 사라집니다. **턴당 카드 1장**, 카드를 써도 돌은 그대로 둡니다(턴 종료 카드 제외).
- 규칙은 화면과 분리된 `js/rules.js` 엔진이 처리하고, `node tests/rules-test.js` 로 시험합니다(규칙·카드·전설 카드 확인 + 무작위 400판).

## 전설 카드 11장 (게임 시작 때 고름)

- 게임을 시작하면 **흑 → 백 순서로 전설 카드 3장 중 1장**을 고릅니다(상대에게는 쓰기 전까지 비공개, 쓰면 공개). 패와 따로 **오른쪽 아래 전설 칸**에 놓이고 판마다 한 번만 씁니다. 일반 카드의 '턴당 1장'과 따로 셉니다.
- 전설 칸의 카드를 누르면 확대되어 **사용 조건과 현재 진행 상황**이 아래에 표시되고, 조건을 채우면 한 번 더 눌러 사용합니다.
- 카드 뽑기 화면(전설 포함)의 **🔄 다시 뽑기**는 판마다 1번(재도전 능력이면 3번)입니다.

| 전설 카드 | 조건 | 효과 |
|---|---|---|
| 🗿 오목의 거신병 | 내 돌 3개 이상 | 내 돌 3개를 바치면 상대 돌이 가장 많은 한 줄을 분쇄 |
| 🧘 무소유 (대응) | 상대가 카드를 쓸 때, 내 패 1장 이상 | 그 카드를 무효로(상대 카드는 소모) · 대가로 내 패 전부 버림 · 차례는 그대로 |
| 🐌 대기만성 | 판에 40수 이상 | 이번 턴 거리 제한 없이 5번 착수 (이번 턴 승리 불가) |
| 🙈 눈 감고 두기 | 상대 돌과 3칸 이상 떨어진 착수 3번 | 3턴 동안 양쪽 판이 어두워져 돌이 안 보임 |
| 🤡 광대의 한 수 | 카드 효과로 내 돌 3개 이상 잃음 | 잃은 돌이 모두 제자리로 귀환, 그 자리의 상대 돌은 밀려남 |
| 🍗 치킨 게임 | 양쪽 모두 3개 이상 이어진 줄 | 동전 던지기 → 진 쪽의 가장 긴 줄이 사라짐 (내 줄일 수도) |
| 🦥 나무늘보 | 카드 없이 6턴 | 패의 카드를 모두 즉시 발동(대상 무작위, 알까기 제외). 쥐고 있는 동안 카드 선택은 무작위 |
| 🪞 따라쟁이 | 상대가 카드를 1장 이상 씀 | 상대가 가장 최근에 쓴 카드를 내 패로 복사 |
| 🎰 올인 | 패 1장 이상 또는 내 돌 3개 이상 | 패 전부 또는 돌 3개를 걸고 슬롯머신 — 같은 그림 3개(50%)면 2배, 꽝이면 잃음 |
| 🐢 토끼와 거북이 | 내 돌이 상대보다 5개 이상 적음 | 이후 나만 4목으로도 승리, 사용 즉시 턴 종료 |
| 👑 왕의 귀환 | 내 돌 1개 이상 | 돌 하나를 왕으로 지정 → 20턴 살아남으면 패 가득 + 새 전설 카드 (왕이 쓰러지면 실패) |

## 시작 능력 5종 (판마다 무작위 1개, 양쪽 공통)

왼쪽 위에 이번 판 맵·라운드·자기장 줄 수와 함께 표시됩니다(마우스를 올리면 설명).

| 능력 | 효과 |
|---|---|
| ☂️ 자연재해 면역 | 내 돌에는 맵 자연재해(녹기·얼음·모래폭풍·쓰나미)가 일어나지 않음 (자기장은 막지 못함) |
| 🎒 넉넉한 주머니 | 패를 5장까지 |
| 🍀 행운 | 카드를 4장 중에서 고름 |
| 🏰 단단한 시작 | 처음 둔 돌 3개는 카드 효과로부터 영구 보호 |
| 🔁 재도전 | 다시 뽑기 3회 |

## 맵 6종과 자기장 (판마다 무작위, 기상 이변 카드로 바뀜)

라운드 = 흑·백이 한 번씩 둔 것(백의 턴이 끝날 때 1 증가). 맵마다 3D 장면의 분위기도 바뀝니다.

| 맵 | 효과 |
|---|---|
| 🏞️ 평원 | 자연재해 없음 (기본 촛불 방) |
| ☀️ 여름 | 5라운드마다 흑돌·백돌이 하나씩 무작위로 녹아 사라짐 |
| ❄️ 겨울 | 5라운드마다 무작위 돌 하나가 2라운드 동안 얼음(누구의 돌도 아님, 줄이 끊김) → 녹으면 원래 주인에게. 눈이 내림 |
| 🌌 우주 | 웜홀: 판의 왼쪽·오른쪽 끝, 위·아래 끝이 이어져 줄이 반대편으로 넘어감 (가장자리가 빛남) |
| 🏜️ 사막 | 8라운드부터 4라운드마다 모래폭풍 — 모든 돌이 무작위 방향으로 한 칸씩 밀림 (승리 줄이 되는 이동은 없음) |
| 🌧️ 장마 | 알까기가 더 미끄럽고, 지진 카드가 2배로 자주 나오며, 지진 때 쓰나미가 한쪽 가장자리 3줄의 돌을 쓸어 감. 비가 내림 |

**⚡ 자기장 (모든 맵)**: 15라운드부터 5라운드마다 바깥 한 줄씩 닫힘(그 줄의 돌은 사라지고 둘 수 없음), 최대 3줄(9×9까지). 닫히기 1라운드 전에 붉은 선과 알림으로 예고합니다.

## 일러스트 · 맵 교체

코드를 고치지 않고 **이미지를 넣고 `js/config.js`에 경로만 적으면** 교체됩니다. 자세한 규격은 [`assets/README.md`](assets/README.md).

- **카드 일러스트**: `assets/cards/`에 PNG(584×428 권장)를 넣고 `config.js`의 `cards`에 경로 지정. 없으면 자동 잉크 그림.
- **맵 분위기**: `config.js`의 `maps`에서 규칙 맵 6종(classic·summer·winter·space·desert·rain)마다 판 이미지, 테이블, 360° 배경, 돌 표면, 조명/안개/촛불/눈·비/카메라를 정할 수 있습니다. 기본은 이미지 없이 색·조명만 다릅니다.

## 아직 구현하지 않은 것 (원본에는 있음)

- 봇 2단계 이상, 온라인 멀티플레이 연결·관전, 카드 도감·티어표, 게임 중 BGM, 카드·맵 내용의 영어 번역 (메인 화면·HUD만 번역됨)
- 효과음은 외부 파일 없이 WebAudio로 만든 임시 소리입니다.
- 투명한 돌 카드는 뺐습니다.

## 파일

모두 같은 전역 공간을 쓰는 일반 스크립트라서(`file://` 더블클릭 실행을 위해) `index.html` 의 불러오는 순서가 중요합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 · HUD · 폰트 선언 · 스크립트 불러오기 순서 |
| `js/config.js` | 일러스트·맵 설정 (여기만 고치면 됨) |
| `js/rules.js` | **규칙 엔진** (원본 규칙 + 일반 카드 19장, 화면과 분리) |
| `js/setup.js` | 공통 상수 · 카드 데이터 · 설정 · 이미지 로더 |
| `js/scene.js` | 3D 장면: 렌더러 · 카메라 · 테이블 · 판 · 촛불 · 별 · 조명 |
| `js/stones.js` | 게임 상태(`G`) · 돌 모델 |
| `js/fx.js` | 연출 도구: tween · 파티클 |
| `js/audio.js` | 효과음 (WebAudio) |
